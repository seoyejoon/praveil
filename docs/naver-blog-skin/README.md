# 프라베일 네이버 블로그 스킨

홈페이지(praveil.com)와 같은 색 · 글꼴 · 사진으로 만든 네이버 블로그 꾸미기 세트입니다.
붙였을 때의 모습은 `out/preview.png` 에서 볼 수 있습니다.

## 올릴 파일 (`out/`)

| 파일                                                        | 크기                              | 넣는 곳                                        |
| ----------------------------------------------------------- | --------------------------------- | ---------------------------------------------- |
| `title.png`                                                 | 966 × 400                         | 리모콘 → 타이틀 → 디자인 → 직접등록            |
| `background.png`                                            | 2560 × 720                        | 리모콘 → 스킨배경 → 직접등록                   |
| `profile.png`                                               | 600 × 600                         | 관리 → 기본 설정 → 블로그 정보 → 프로필 이미지 |
| `widget-hours.png`                                          | 340 × 700 (보이는 크기 170 × 350) | 위젯 직접등록 (`widgets.html`)                 |
| `widget-reserve.png` · `widget-home.png` · `widget-map.png` | 340 × 128 (보이는 크기 170 × 64)  | 위젯 직접등록 (`widgets.html`)                 |
| `post-header.png`                                           | 1720 × 560                        | 글 맨 위                                       |
| `post-divider.png`                                          | 1720 × 220                        | 글 중간 소제목 띠                              |
| `post-footer.png`                                           | 1720 × 1435                       | 글 맨 아래 (진료시간 · 오시는 길 · 전화)       |
| `mobile-cover.png`                                          | 1080 × 1080                       | 모바일 앱 → 블로그 홈 → 홈편집 → 커버 이미지   |

`preview.png` 는 확인용이라 올리지 않습니다.

## 붙이는 순서

1. **레이아웃**: 관리 → 꾸미기 설정 → 레이아웃 · 위젯 설정 → 2단, 사이드바 오른쪽.
   기본 위젯 중 프로필 · 카테고리만 남기고 나머지(방문자 · 달력 · 태그 등)는 끕니다.
2. **리모콘** (꾸미기 설정 → 세부 디자인 설정)
   - 스킨배경: 직접등록 → `background.png`, 위치 가운데 · 반복 안 함, 바탕색 `#f6f2ec`
   - 타이틀: 블로그 제목 표시 끄기, 영역 높이 400, 직접등록 → `title.png`
   - 블로그 메뉴: 바탕 `#1d1a17`, 글자 `#c2b096`, 선택한 메뉴 `#ffffff` (타이틀 아래 짙은 띠와 이어지게). 구분선 색을 고를 수 있으면 `#7d6649`
   - 포스트 영역 · 위젯 바탕: `#ffffff`, 테두리 · 구분선 `#e8e2d9`, 강조 글자 `#a88e6a`
3. **프로필**: `profile.png` 를 블로그 프로필 이미지로 올립니다.
4. **위젯 등록**: `widgets.html` 의 블록을 하나씩 위젯 직접등록에 그대로 붙여 넣습니다.
   위젯 그림은 홈페이지 서버(`https://praveil.com/images/naver-blog/`)에 있어 주소를 따로 만들 필요가 없습니다.
   레이아웃 화면에서 프로필 아래로 진료시간 → 네이버 예약 → 홈페이지 → 오시는 길 순서로 끌어다 놓습니다.
5. **글 머리 · 꼬리**: `post-header.png` · `post-footer.png` 를 넣은 빈 글을 스마트에디터 **내 템플릿**으로 저장해 두면 글마다 다시 올리지 않아도 됩니다. 소제목 띠(`post-divider.png`)는 필요할 때 본문 중간에 넣습니다.
6. **모바일 커버**: 네이버 블로그 앱 → 내 블로그 → 홈편집 → 커버 이미지에 `mobile-cover.png` 를 올립니다.

## 블로그 글 3개

`posts/` 에 오시는 길 · 주차 안내, 예약 안내, 병원명 변경 안내 본문(`*.txt`)이 있습니다.
글에 들어가는 그림은 `posts.html` 에서 그리고 `out/posts/` 에 저장됩니다 (표지 · 본문 카드).
본문의 `[그림: …]` 자리에 그림을 넣고, 소제목 띠 · 글 꼬리는 `out/post-divider.png` · `out/post-footer.png` 를 씁니다.

## 고치는 법

문구 · 사진을 바꿀 때는 `skin.html` 을 고친 뒤 다시 그립니다.

```sh
pnpm install --frozen-lockfile   # 프리텐다드 글꼴
node docs/naver-blog-skin/render.mjs
```

- 위젯 그림은 `render.mjs` 가 `public/images/naver-blog/` 에도 복사합니다. 서버 캐시가 30일이라, 그림을 고치면 파일 이름을 바꿔(예: `widget-hours-2.png`) 올리고 `widgets.html` 주소도 같이 바꿔 주세요.
- 진료시간 · 전화 · 주소는 `src/lib/data/mock/hospital.ts` 값을 옮겨 적은 것입니다. 바뀌면 `skin.html` 도 같이 고쳐 주세요.
- 원장님 사진은 홈페이지와 같은 보정본 `public/images/photos/retouched/laser.jpg` 를 씁니다.
- 지난 타이틀 시안(A · A-1 · A-3 · B · C · D, A-2 흰 바탕 · 짙은 판)은 git 기록에 남아 있습니다.

## 확인 필요

- 모바일 커버 권장 크기: 네이버 앱 화면마다 위 · 아래가 잘려 보일 수 있어, 로고는 위쪽, 사진은 아래쪽에 두었습니다. 올린 뒤 앱에서 한 번 확인해 주세요.
- 글 꼬리 글자 크기: 휴대폰에서는 글 그림이 약 1/5 크기로 보여 글 꼬리의 작은 글씨가 잘 안 읽힐 수 있습니다.
- 블로그 주소: 홈페이지 소식 연동은 아직 `blog.naver.com/newrizzclinic` 을 읽습니다. 블로그 이름 · 주소를 바꾸면 알려 주세요.
- 카카오톡 상담 위젯: 채널 주소가 정해지면 같은 모양으로 추가합니다.
- 리모콘 메뉴 이름은 네이버 화면 개편에 따라 조금 다를 수 있습니다.
