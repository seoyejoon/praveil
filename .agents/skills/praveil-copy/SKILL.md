# 원고 쓰기

## 말투
- 원장이 진료실에서 환자에게 설명하듯: 짧게, 쉽게, 차분하게. 한 문장에 한 가지 내용.
- `~합니다` · `~드립니다` · `~해 주세요`. 반말 · 감탄사 · 이모지 금지.
- 전문용어는 처음 한 번만 괄호로 풀어 줍니다. 예: `보툴리눔 톡신(근육 움직임을 줄이는 주사)`
- "~에 따르면", "연구에서", "증례", "대상자 n명" 같은 논문 말투는 쓰지 않습니다. 근거는 출처 링크로만 보여 줍니다.

## 금지
| 금지 | 대신 |
|---|---|
| 최고 · 유일 · 최초 · 가장 · 완벽 · 1위 · 100% | 빼거나 구체적인 사실로 |
| 반드시 좋아집니다 · 확실한 효과 · 영구적 | 변화를 기대할 수 있습니다 · 사람마다 다릅니다 |
| 통증 없음 · 부작용 없음 | 통증이 적은 편입니다 · 드물게 ~ 생길 수 있습니다 |
| 다른 병원 · 장비보다 낫다 | 방식이 다릅니다 |
| 지어낸 가격 · 횟수 · 기간 · 실적 · 후기 · 별점 | `// 확인 필요:` 주석 |

## 부작용 쓰는 법
"드물게 ○○이 생길 수 있어, ○○을 고려해 시술합니다. ○○이 있으면 바로 알려 주세요."
겁을 주는 사례 · 확률 · 논문 결과는 넣지 않습니다.

## 세부 시술 카드 (`items`)
- 환자가 보는 짧은 설명: 부위 · 고민만 적습니다. 예: `이마 · 미간 · 눈가`, `집속 초음파로 처진 윤곽 · 턱선 관리`
- "~ 확인", "~ 상담" 으로 끝내지 않습니다 (병원 내부 메모처럼 읽힘).

## 표기
- 가운뎃점 ` · ` (앞뒤 한 칸), 물결 `~` 로 범위 (`1~3일`)
- 강조는 FAQ 답변 안에서 `**굵게**` 한 번 정도만
- 문단 사이는 빈 줄 하나

## 출처 링크
- FAQ 답변의 문단 끝에 `[이름](주소)`. 화면에서는 자동으로 답변 아래 "참고 자료" 한 줄로 모입니다.
- 공식 기관 · 제조사 · 학회 자료 우선 (FDA, 미국피부과학회 AAD, 식약처, 제조사).
- 넣기 전에 `curl -sIL -o /dev/null -w "%{http_code}" <주소>` 가 200 인지 확인. 아니면 넣지 않습니다.

## 확인 필요 표시
모르는 사실은 지어내지 말고 그 항목 바로 위에:
```ts
// 확인 필요: 실제 사용하는 톡신 제품명 · 제조사
```
PR 본문에 페이지별로 모아서 적습니다.
